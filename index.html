Сетка: тап по клетке ставит удар (повторный тап меняет громкость 2→3→1→0). На компьютере можно «рисовать» зажатой мышью, правая кнопка — стереть.

Пиано-ролл: кнопка ♪ на дорожке. Призрачные (ghost) ряды — ноты выбранного лада; «ЛАД» подтягивает новые ноты в гамму. Клавиатура как в FL: белые/чёрные, жёлтая линия — граница октавы.

Инструменты — подключаемые плагины (см. SDK). Драм-дорожка тоже мелодична: сэмпл играется по нотам с изменением высоты.

SDK — подключить свой синтезатор / ромплер
SeqStudio.registerInstrument({ id:'myChip', name:'MY CHIP', // ctx — AudioContext (или Offline при экспорте), // out — выход дорожки (уже с громкостью/паном) create(ctx, out){ return { noteOn(t, midi, vel){ const o=ctx.createOscillator(), g=ctx.createGain(); o.type='square'; o.frequency.value=440*Math.pow(2,(midi-69)/12); g.gain.setValueAtTime(.3*vel, t); g.gain.exponentialRampToValueAtTime(.001, t+.4); o.connect(g); g.connect(out); o.start(t); o.stop(t+.45); }, noteOff(t, midi){}, stopAll(t){} }; } }); // добавить свой сэмпл в банк: // SeqStudio.registerSample({id:'x', name:'X', buffer})

Плагин получает контекст при каждом рендере, поэтому живое исполнение и офлайн-экспорт работают одинаково. Будущие ромплеры/синты на этом же стеке подключаются одним скриптом.
